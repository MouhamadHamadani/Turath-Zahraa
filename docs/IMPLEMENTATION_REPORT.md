## 4. New issues found

| Severity | Issue |
| --- | --- |
| Medium | PHP upload limits: CLI reports `upload_max_filesize=16M`, `post_max_size=16M`. Filament allows audio to 500 MB and PDFs to 100 MB, Livewire now allows 500 MB, but the Apache `php.ini` must be raised too, or large uploads fail. Not changed (outside the repo). |
| Medium | `Schema::defaultStringLength(191)` in `AppServiceProvider` makes every `string()` column 191 chars. A title longer than 191 characters will error in strict mode. Left as is; remove it and widen the columns if long titles are expected. |
| Medium | Photo/Document `web` conversion is queued (`QUEUE_CONNECTION=database`). Without `php artisan queue:work` it is never generated (the `thumb` conversion is synchronous). |
| Medium | `followers_count` defaults to 15000 — the number the site already claimed. It cannot be derived from the DB; the foundation must confirm it. |
| Low | Fortify `home` is `/admin`, so a non-admin who signs in at `/login` lands on a 403. Harmless while registration is off; revisit before the members area. |
| Low | `public/images/widgets/*.jpg` are 1–8 MB each and no longer referenced; `images/hero.png` is 680 KB. Compress or delete before they are used. |
| Low | Alpine logs `Uncaught (in promise) {isFromCancelledTransition: true}` when a dropdown is toggled again mid-transition. Cosmetic console noise from Alpine's `x-transition`. |
| Low | `APP_FAKER_LOCALE=ar_IQ` in the local `.env` is not a Faker locale. Factories use `ar_SA` directly, so nothing breaks. |
| Low | `database/migrations/…000005_create_archive_tables.php` comment mentions a `scan` collection for documents; the model uses `pages`. Comment only. |
| Info | Landing counts are cached for 5 minutes, so a new book can take up to 5 minutes to show in the count. |
| Info | Seeded `privacy`/`terms`/`rights` pages are **published** with a visible "draft" notice so footer links resolve. Replace the text before launch. |

## 9. How to run

### Setup
```bash
composer install
npm install
cp .env.example .env          # skip if .env exists
php artisan key:generate      # skip if APP_KEY is set
```
In `.env`: MySQL `DB_*`, `APP_LOCALE=ar`, and

```
ADMIN_NAME=...
ADMIN_EMAIL=...
ADMIN_PASSWORD=...      # 12+ characters
AUDIO_DISK=public       # or s3 later
```

```bash
php artisan migrate         # additive only
php artisan storage:link
php artisan db:seed         # categories, milestones, pages, then the admin (refuses without ADMIN_*)
npm run build               # or: npm run dev
php artisan serve
php artisan queue:work      # needed for Photo/Document "web" conversions
php artisan test
```
Admin panel: `/admin`. The admin seeder sets the password only when the user is created; a later change to `ADMIN_PASSWORD` does not overwrite it. To seed content without an admin: `php artisan db:seed --class=CategorySeeder` (also `PageSeeder`, `MilestoneSeeder`).
